  <b><a href="README.md">🇬🇧 English</a></b> | <b><a href="README_FA.md">🇮🇷 فارسی</a></b>

یک بازی مار جنگی و تاکتیکی فوق‌سریع و هوشمند که با **مدل تصمیم‌گیری سیستم ۱ لایا ([`convaiinnovations/laya`](https://huggingface.co/convaiinnovations/laya))** و با شتاب سخت‌افزاری **کارت گرافیک انویدیا (CUDA)** بر بستر FastAPI اجرا می‌شود.

این پروژه به یک **موتور تصمیم‌گیری چندوجهی تاکتیکی** در کنار شبیه‌ساز پیش‌بینی آینده، پهپادهای دشمن پویا، سیستم سلاح لیزری پلاسما، قابلیت جابجایی ابعاد زمین و اکوسیستم ۴ گانه آیتم‌های جنگی مجهز شده است.

## ⚔️ قابلیت‌های میدان نبرد تاکتیکی (Tactical Battle Arena)

* **🛸 پهپادهای متخاصم هوش مصنوعی (دشمنان پویا):**
  * پهپادهای جنگی خودکار در زمین گشت‌زنی کرده و مار را به صورت فعال تعقیب می‌کنند.
  * برخورد با دشمن باعث کسر ۱ واحد از جان مار (HP) و لرزش شدید صفحه می‌شود.
* **💥 سلاح پرتابه‌ای پلاسما (سیستم تیراندازی):**
  * با داشتن مهمات (Ammo)، مار می‌تواند پرتوهای پرسرعت پلاسما را در خط دید خود شلیک کند.
  * برخورد مستقیم گلوله، پهپاد دشمن را در انفجاری از ذرات متلاشی کرده (+۲۰۰ امتیاز) و جعبه‌های مهمات روی زمین رها می‌سازد.
* **🌀 جهش کوانتومی و گسترش زمین (Dimension Warp):**
  * هنگام گیر افتادن در گوشه‌های زمین یا بسته شدن مسیر توسط دیوار، مار می‌تواند طلسم تغییر ابعاد را اجرا کند تا **۱ ستون یا ردیف جدید به صورت پویا به زمین اضافه شود** و راه فرار جدیدی خلق گردد!
* **📦 اکوسیستم آیتم‌های ۴ گانه:**
  * 🍎 **انرژی بیومس (غذا):** افزایش طول مار، امتیاز پایه و شارژ انرژی مانا.
  * ⚡ **سلول‌های مهمات (Ammo):** شارژ مجدد ۳ گلوله پلاسما برای شلیک به دشمنان.
  * ❤️ **قلب حیات (Heart):** بازیابی +۱ جان (تا سقف ۳ جان) برای بقا در برابر ضربات دشمن.
  * 🎁 **جعبه اسرارآمیز تاکتیکی (Gift):** فعال‌سازی قابلیت‌های فوق‌العاده مانند **انجماد کامل پهپادها (EMP Freeze)** یا شارژ ۱۰۰٪ مانا.
* **🧠 سیستم تصمیم‌گیری چندوجهی لایا:**
  * در هر لحظه، لایا چندین تصمیم تاکتیکی را به طور همزمان در یک مرحله ارزیابی می‌کند:
    * `tactical_action`: شلیک، مانور فرار و درمان، گسترش زمین، جمع‌آوری تیر، یا شکار غذا.
    * `move`: انتخاب امن‌ترین و بهینه‌ترین جهت حرکت (بالا، پایین، چپ، راست).
    * `threat_level`: سطح تهدید محیطی (امن، درگیری جنگی، خطر مرگبار).
* **🛡 ایمنی دوگانه هندسی و فیزیکی:**
  * محاسبات پیش‌بینی آینده و تست خروج به دم، برخورد به دیواره‌ها و گره خوردن در خود را به صفر می‌رساند.

## 🏗️ معماری سیستم نبرد

```mermaid
graph TD
    A[کلاینت نبرد: snake.html] -->|ارسال وضعیت جنگی + سوالات| B[سرور FastAPI: server.py]
    B -->|سریال‌سازی وضعیت + معیارهای معنایی| C[مدل لایا ModernBERT روی GPU]
    C -->|توزیع احتمالات تاکتیکی و حرکتی| B
    B -->|دستور شلیک، جابجایی و جهت نهایی| A
    A -->|اعمال حرکت و شلیک سلاح| D[بوم پویا میدان نبرد]

      E[رهگیری خط آتش لیزر]

      G[محاسبه ظرفیت فضایی با Flood Fill]
      H[تنظیم پویا ابعاد زمین نبرد]
    end

    A <--> موتور دوگانه تصمیم‌گیری تاکتیکی
```

## 🚀 راهنمای نصب و اجرای سریع

### پیش‌نیازها
* ویندوز، لینوکس یا مک دارای **پایتون نسخه ۳.۱۰ به بالا**.
* کارت گرافیک انویدیا با پشتیبانی از CUDA (یا پردازنده چندهسته‌ای).
* فایل‌های وزن مدل لایا به صورت محلی:
  ```bash
  git clone https://huggingface.co/convaiinnovations/laya C:\AI\Models\laya
  ```

### مرحله ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### مرحله ۲: اجرای سرور تاکتیکی
```bash
# در صورت نیاز به تغییر مسیر مدل:
set LAYA_MODEL_PATH=C:\AI\Models\laya

# اجرای سرور
python -u server.py
```
یا کافی است فایل **`start-game.bat`** را اجرا کنید.

### مرحله ۳: ورود به بازی در مرورگر
آدرس زیر را در مرورگر باز کنید:
```
http://localhost:8080/snake
```
* **کلید Space (فاصله):** شلیک دستی پرتو لیزر پلاسما
* **کلید E:** باز کردن ۱ ستون جدید به سمت چپ (Warp Grid)
* **کلید P:** توقف / ادامه بازی (Pause)
* **کلیدهای جهت‌نما یا WASD:** کنترل دستی مار
