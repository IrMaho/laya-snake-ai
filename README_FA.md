یک بازی مار جنگی و تاکتیکی فوق‌سریع و هوشمند که توسط **مدل تصمیم‌گیری سیستم ۱ لایا ([`convaiinnovations/laya`](https://huggingface.co/convaiinnovations/laya))** و با شتاب سخت‌افزاری **کارت گرافیک انویدیا (CUDA)** بر بستر FastAPI اجرا می‌شود.

این پروژه معماری هوش مصنوعی هیبریدی مدرنی را به نمایش می‌گذارد: **شبیه‌ساز تحلیلی کلاینت (Forward Virtual Lookahead + Flood Fill)** بقای هندسی و فیزیکی مار را تضمین می‌کند و **مدل زبانی سیستم ۱ لایا (Laya System-1 Agent)** به عنوان فرمانده میدان نبرد، اولویت‌های استراتژیک چندمعیاره مانند هدف‌گیری لیزری، فرار تاکتیکی، استفاده از ظرفیت محدود جهش کوانتومی، مدیریت مهمات و جمع‌آوری نانوبوت‌های سلامتی را در کسری از میلی‌ثانیه انتخاب می‌کند.

## ⚔️ قابلیت‌ها و مکانیک‌های پیشرفته میدان نبرد

### ۱. 🌀 جهش کوانتومی با سقف محدود ۵ بار (Strict 5-Warp Quota)
* **پایان گسترش نامحدود:** مار در طول هر سکتور حداکثر **۵ بار** مجاز به باز کردن و گسترش ابعاد زمین بازی (+۱ ستون یا سطر در ۴ جهت) است.
* **شمارنده و نمایشگر HUD:** وضعیت سهمیه در نوار بالای بازی به شکل زنده نمایش می‌یابد: `WARP: 100% (5/5 Left)`.
* **کنترل هوشمند لایا با تگ `[EXHAUSTED/PROHIBITED]`:** به محض مصرف هر ۵ فرصت جهش، دکمه غیرفعال شده و در لایه سرور، معیار جهش کوانتومی با این تگ علامت‌گذاری می‌شود تا مدل لایا دیگر تلاش بیهوده برای بزرگ کردن زمین نکند و اولویت خود را بر مانورهای فرار و نبرد بگذارد.

### ۲. 🏆 هدف مأموریت و سیستم فتح سکتور (Sector Victory - 2000 Pts Target)
* **پایان حلقه بی‌نهایت:** بازی دارای هدف غایی و مأموریت مشخص است. هدف مار رسیدن به **امتیاز ۲۰۰۰** در هر سکتور می‌باشد.
* **پنجره جشن پیروزی سکتور:** به محض رسیدن به امتیاز هدف، پنجره اختصاصی پیروزی به همراه آمار تفکیکی (امتیاز کسب‌شده، تعداد جهش‌های مصرف‌شده، جان باقی‌مانده) و سرود صوتی پیروزی پخش می‌شود.
* **ارتقای مرحله (Next Sector):** با کلیک روی دکمه `▶ Next Sector`، سرعت پهپادها و شدت حملات افزایش یافته و سکتور بعدی آغاز می‌شود.

### ۳. 🛡️ سیستم بقا و ۵ جان نئونی با سپر نامرئی (5-Heart Vitality & i-Frames)
* **حیات مقاوم:** مار به جای مرگ با یک ضربه، دارای **۵ قلب سلامت (HP=5)** است.
* **سپر ضدضربه (Invincibility Frames):** پس از هر بار اصابت به دشمن یا خطر، **۲۵ تیک سپر نامرئی/نئونی** به همراه حباب نوری فیروزه‌ای فعال می‌شود تا از کشته شدن ناگهانی مار بر اثر کمبوهای زنجیره‌ای جلوگیری کند.
* **سیستم بازتاب خودکار از دیوارها (Perimeter Deflector):** مار در صورت اصابت اضطراری به مرزهای صفحه، با یک مانور بازتاب هوشمند به مسیر آزاد تغییر جهت می‌دهد.

### ۴. 🎥 ریکوردر داخلی ۶۰ فریم بدون پرش (Zero-Flicker 60 FPS Video Recorder)
* **ریشه‌یابی و رفع باگ پرش نرم‌افزارهای خارجی:** در سیستم‌های ویندوزی با کارت گرافیک انویدیا، مکانیزم سخت‌افزاری Multi-Plane Overlay (MPO) در صورت وجود افکت‌های CSS `backdrop-filter: blur` یا لرزش‌های کانتینر روت، هنگام کپچر با ابزارهایی مثل OBS یا Windows Game Bar دچار تضاد بافر و ایجاد فریم‌های سیاه یا چشمک‌زن متوالی می‌شد.
* **راهکار اختصاصی:** تمام بلورهای سنگین GPU حذف و رنگ‌های عمیق سایبرپانک `#050811` جایگزین شدند. همچنین یک **ریکوردر بومی مرورگر** با دکمه `🎥 Rec (60fps)` اضافه شد که مستقیماً فریم‌ها را از طریق استاندارد `canvas.captureStream(60)` و `MediaRecorder` ضبط کرده و ویدیوی بسیار باکیفیت و کریستالی `.webm` را با ۱ کلیک دانلود می‌کند.

### ۵. 💥 سلاح پرتابه‌ای لیزر پلاسما (Plasma Beam Cannon)
* **شلیک در خط دید مستقیم:** مار با قرار گرفتن در راستای افقی یا عمودی پهپاد دشمن، پرتو پرسرعت نئونی شلیک می‌کند.
* **انفجار دشمن و امتیازگیری:** برخورد پرتو لیزر به پهپاد دشمن باعث انفجار آن (+۲۵۰ امتیاز) و پخش ترکش‌های نوری نئونی روی صفحه می‌شود.

### ۶. 🛸 پهپادهای جنگی متخاصم هوش مصنوعی (Hostile Drones)
* پهپادهای شکارچی در فواصل ایمن از سر مار متولد می‌شوند و با الگوریتم تعقیب متعادل به سمت مار پیشروی می‌کنند.
* سیستم صوتی و بصری نزدیک شدن پهپاد به مار، حس اضطرار تاکتیکی را به اوج می‌رساند.

### ۷. 📦 اکوسیستم آیتم‌های ۴ گانه میدان نبرد
| آیکون | نام آیتم | اثر در گیم‌پلی |
| :---: | :---: | :--- |
| 🍎 | **انرژی بیومس (غذا)** | افزایش طول مار، کسب امتیاز و پر کردن خازن انرژی مانای جهش |
| ⚡ | **پاد مهمات (Ammo)** | شارژ مجدد +۳ تیر سلاح لیزر پلاسما |
| ❤️ | **نانوبوت‌های تعمیرات (Heart)** | بازیابی +۱ جان مار (تا سقف ۵ جان کامل) |
| 🎁 | **مکعب کوانتومی EMP (Gift)** | انجماد کامل تمامی پهپادهای دشمن برای چند ثانیه و شارژ کامل انرژی مانا |

### ۸. 🔊 سینت‌سایزر صوتی تحت وب (Procedural Web Audio Engine)
* **۱۰۰٪ مستقل بدون نیاز به دانلود فایل صوتی خارجی:** تمامی جلوه‌های صوتی شامل شلیک لیزر، انفجار پهپادها، برداشتن آیتم‌ها، آژیر هشدار خطر، جهش کوانتومی و سرود پیروزی مستقیماً توسط پردازشگر فرکانسی Web Audio API مرورگر سنتز و پخش می‌شوند.
* دارای دکمه روشن/خاموش صدا (`🔊 SFX: ON`) و کلید میانبر `M`.

### ۹. 🧠 موتور تصمیم‌گیری قاطع لایا با تگ‌های PRIORITY
* سیستم ارسال پرامپت پویا برای هر انتخاب، معیارهای سنجش شفاف و رتبه‌بندی‌شده (`PRIORITY-1` تا `PRIORITY-3`) تولید می‌کند. این معماری تردید هوش مصنوعی را کاملاً از بین برده و تصمیمات قاطعانه‌ای در شرایط بحرانی می‌گیرد.

## ⌨️ جدول کلیدهای میانبر و کنترل‌ها

| کلید / دکمه | عملکرد |
| :--- | :--- |
| **Space (فاصله)** | شلیک دستی پرتو لیزر پلاسما |
| **کلید E** | جهش کوانتومی و افزایش ۱ ستون به سمت چپ زمین (حداکثر ۵ بار) |
| **کلید P** | توقف / ادامه بازی (Pause / Resume) |
| **کلید R** | بازنشانی و شروع مجدد دست جدید (Reset) |
| **کلید M** | قطع و وصل صدای سینت‌سایزر (Mute / Unmute) |
| **کلیدهای جهت‌نما یا WASD** | هدایت دستی مار (در صورت نیاز به دخالت کاربر) |
| **دکمه `🤖 AI: ON`** | سوئیچ میان هدایت هوش مصنوعی لایا و حالت کنترل دستی |
| **دکمه `🎥 Rec (60fps)`** | شروع و پایان فیلم‌برداری ۶۰ فریم بدون پرش از محیط بازی و دانلود ویدیو |

## 🚀 راهنمای نصب و اجرای سریع

### پیش‌نیازها
* سیستم‌عامل ویندوز، لینوکس یا مک دارای **پایتون نسخه ۳.۱۰ به بالا**.
* کارت گرافیک انویدیا با درایور بروز و پشتیبانی از CUDA (یا پردازنده چندهسته‌ای).
* وزن‌های مدل هوش مصنوعی لایا دانلودشده به صورت محلی:
  ```bash
  git clone https://huggingface.co/convaiinnovations/laya C:\AI\Models\laya
  ```

### مرحله ۱: نصب نیازمندی‌های پایتون
```bash
pip install -r requirements.txt
```

### مرحله ۲: اجرای سرور هوش مصنوعی
```bash
# در صورت نیاز به تنظیم مسیر دلخواه برای مدل:
set LAYA_MODEL_PATH=C:\AI\Models\laya

# اجرای مستقیم سرور
python -u server.py
```
> **نکته:** در ویندوز می‌توانید به راحتی فایل **`start-game.bat`** را دو بار کلیک کنید تا سرور به صورت خودکار پیکربندی و اجرا شود.

### مرحله ۳: ورود به بازی در مرورگر
مرورگر مدرن خود (کروم، اج، فایرفاکس یا بریو) را باز کرده و به نشانی زیر بروید:
```
http://localhost:8080/snake
```

## 📊 مشخصات عملکردی و سخت‌افزاری

| شاخص | مقدار اندازه‌گیری شده | وضعیت |
| :--- | :--- | :--- |
| **زمان پاسخگویی استنتاج (CUDA GPU)** | ۳۵ تا ۶۵ میلی‌ثانیه | فوق‌سریع و روان (Ultra-Low Latency) |

| **مصرف حافظه گرافیکی (VRAM)** | حدود ۱.۲ گیگابایت | سبک و بهینه برای اجرای همزمان سایر برنامه‌ها |
